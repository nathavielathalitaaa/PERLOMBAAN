# System Architecture — AI Competition Mentor (V0.1)

## 1. Architectural Philosophy

AI Competition Mentor V0.1 is designed with a **Research-Driven, Evidence-Based, Layered Architecture**. The fundamental goal is to decouple the collection and curation of verifiable empirical data from downstream statistical modeling and machine learning algorithms.

```
+-------------------------------------------------------------------------+
|                       Analysis & Export Layer                           |
|       (CompetitionMatrixBuilder, CompetitionExporter, Pandas Engine)     |
+-------------------------------------------------------------------------+
                                    |
+-------------------------------------------------------------------------+
|                       Domain Service Layer                              |
|   (RequirementService, IndicatorService, CompetencyService, Auditor)   |
+-------------------------------------------------------------------------+
                                    |
+-------------------------------------------------------------------------+
|                    Data Validation & Schemas (DTO)                      |
|           (Pydantic V2 Models, Strict Provenance Typing Enums)           |
+-------------------------------------------------------------------------+
                                    |
+-------------------------------------------------------------------------+
|                   Object Relational Mapping (ORM)                       |
|           (SQLAlchemy 2.0 Declarative Models & SQLite Engine)           |
+-------------------------------------------------------------------------+
                                    |
+-------------------------------------------------------------------------+
|                   Document Ingestion & Staging                          |
|         (PyMuPDF / pymupdf Reader, SHA-256 Verifier, Staging Text)      |
+-------------------------------------------------------------------------+
```

## 2. Core Architectural Components

### 2.1 Database & Persistence Layer (`src/database/`)
- **Engine**: SQLite 3.46+ using SQLAlchemy 2.0 ORM.
- **Foreign Key Enforcement**: `PRAGMA foreign_keys=ON;` is enforced at the database connection driver level on every connection.
- **UUID Primary Keys**: Every entity uses a 36-character UUIDv4 primary key to allow distributed research data ingestion without ID collision.
- **Referential Integrity**: Cascading deletes ensure orphan prevention (`ondelete="CASCADE"`), while check constraints enforce integrity on polymorphic evidence targets.

### 2.2 Data Ingestion & Validation (`src/data_collection/`)
- Implemented with **Pydantic V2**.
- All data entering the service layer is validated for type safety, length constraints, and semantic sanity.
- Enums strictly govern provenance and classifications:
  - `SourceStatus`: `EXPLICIT`, `INFERRED`, `UNVERIFIED`.
  - `Classification`: `MANDATORY_ELIGIBILITY`, `EVALUATION_CRITERIA`, `DISQUALIFICATION_RULE`, `GENERAL_GUIDELINE`.

### 2.3 Document Processing Layer (`src/document_processing/`)
- Powered by `pymupdf`.
- **Cryptographic Provenance**: Computes SHA-256 checksums of raw PDF files upon registration.
- **Staging Isolation**: All raw extracted text is treated as unverified staging data (`is_verified=False`). No automated extraction is written directly to the database as official requirements without human researcher validation.

### 2.4 Research Services (`src/requirement_extraction/`, `src/indicator_mapping/`, `src/competency_mapping/`)
- Business and domain logic encapsulation.
- Enforces uniqueness of taxonomy codes and link integrity.
- Handles bidirectional relationships between requirements, indicators, competencies, and supporting evidence.

### 2.5 Analysis & Exporter Layer (`src/analysis/`)
- **CompetitionMatrixBuilder**: Synthesizes the Competition Requirement Matrix by aggregating requirements, scoring indicators, mapped competencies, and source evidence citations.
- **Data Flattening**: Converts nested matrices into flat Pandas DataFrames for statistical and scientific processing.
- **Lossless Exports**: Generates both machine-readable JSON (with complete hierarchy and provenance) and tabular CSV.

### 2.6 Evaluation & Auditing (`src/evaluation/`)
- **DataIntegrityAuditor**: Conducts automated audits on research data.
- Detects scientific integrity violations (e.g., requirements marked `EXPLICIT` that lack evidence citations, or documents whose physical file hash does not match the database).

## 3. Extensibility for Future Versions

The architecture is prepared for future phases:
- **V0.4 (Statistical Analysis)**: Can consume the flat Pandas DataFrames generated by `CompetitionMatrixBuilder.to_dataframe()`.
- **V0.7 (Machine Learning)**: Can pull ground-truth triples (`Requirement`, `Indicator`, `Evidence`) to train NLP feature extractors or embedding representations without changing the schema.

TEMA KEGIATAN 

Clean Code Web Programming berfokus pada pengembangan 

aplikasi web modern yang tidak hanya memiliki tampilan 

antarmuka yang menarik, tetapi juga mengedepankan kualitas 

arsitektur kodingan yang bersih (Clean Code), kerapihan struktur 

proyek, kemudahan perawatan (Maintainability), dan efisiensi 

performa sesuai standar industri. 

Tema utama INFORMIND FEST VOL. II adalah "Compile Your 

Future, Deploy Your Impact" yang menjadi landasan utama bagi 

seluruh peserta. Karya yang dikembangkan wajib memilih salah 

satu dari 4 (empat) subtema pilihan berikut: 

1. EKRAF(Ekonomi Kreatif) 

Solusi web untuk digitalisasi UMKM lokal, platform ekonomi 

kreatif, marketplace jasa/karya independen, atau tools 

bisnis kreator. 

 

 

 

 

3 
 



 

 
2. STEM (Science Technology and Mathematics) 

Platform web edu-tech, simulasi sains/matematika 

interaktif, portal kuis koding, atau alat bantu produktivitas 

akademis. 

 

3. SOCIOTECH (Social Technology) 

Platform web pemberdayaan masyarakat, sistem 

transparansi sosial, pengaduan fasilitas lingkungan, atau 

penanggulangan masalah publik. 

 

4. FINTECH (Finance Technology) 

Aplikasi web pencatatan keuangan UMKM/komunitas, kasir 

digital ringan (POS), pelacak anggaran, atau edukasi literasi 

keuangan.

DESKRIPSI PERLOMBAAN 

INFORMIND FEST VOL. II adalah seminar sekaligus kompetisi 

nasional yang diselenggarakan sebagai wadah kreativitas dan 

inovasi siswa/mahasiswa dalam menguji kecakapan 

merancang aplikasi web modern. Pada cabang Lomba Clean 

Code Web Programming, seleksi awal diawali dengan 

pengumpulan Abstrak/Proposal Ide sebagai tahap filtering ide 

karya (sama seperti lomba UI/UX). Selanjutnya, karya kode 

peserta diuji melalui System Automated (CI/CD build check, linter 

ESLint, & JSCPD) sebelum masuk ke tahap final berupa 

Wawancara dan Juri Cek Code.

KETENTUAN PERLOMBAAN DAN SPESIFIKASI 
TEKNIS 

1. Peserta diberi kebebassan untuk memilih satu subtema 

yang telah disediakan panitia. 

2. Stack teknologi bebas/direkomendasikan: ekosistem 

JavaScript/TypeScript (Vanilla JS, React, Next.js) serta 

PHP (Laravel, CodeIgniter). 

3. Diperbolehkan menggunakan CSS Framework seperti 

Tailwind CSS atau Bootstrap. 

4. Proyek wajib disimpan dalam repositori GitHub publik milik 

tim dan menyertakan file README.md berisi cara 

menjalankan proyek. 

5. Kode tidak boleh mengandung unsur SARA, pornografi, 

perjudian, maupun hal yang melanggar hukum di 

Indonesia. 

6. Hak kepemilikan karya tetap menjadi milik peserta, namun 

panitia berhak mendokumentasikan karya untuk publikasi 

kegiatan. 

 

 

11 
 



 

 

KETENTUAN DISKUALIFIKASI 

1. Jika peserta terbukti melakukan plagiarisme atau 

menggunakan karya milik orang lain (skor JSCPD > 50%). 

2. Jika peserta tidak memenuhi persyaratan administrasi 

atau pengumpulan abstrak/laporan ide. 

3. Jika peserta sengaja memanipulasi file linter atau 

menggunakan komentar // eslint-disable secara agresif 

untuk mengelabui auto-grading. 

4. Jika peserta mengumpulkan karya melebihi batas waktu 

yang ditentukan panitia. 

5. Jika peserta melanggar ketentuan, spesifikasi teknis, atau 

regulasi umum INFORMIND FEST VOL. II. 

6. Keputusan panitia dan dewan juri adalah mutlak yang tidak 

dapat diganggu gugat.

SISTEM PERLOMBAAN 
 

1. Tahap Kesatu 

a. Peserta mendaftar melalui Google Form yang telah 

disediakan. 

b. Peserta mengikuti Technical Meeting minimal dihadiri 

oleh 1 orang perwakilan tim. 

c. Peserta mengumpulkan karya melalui Google Form 

yang berisikan tautan Google Drive meliputi: 

• Pernyataan orisinalitas karya 

• Laporan karya yang berisikan: 

• Latar belakang 

• Nama dan tema karya 

• Tech stack 

• Alur arsitektur web 

d. Berkas abstrak/laporan ide dinilai oleh panitia/juri 

untuk menyaring ide-ide paling inovatif & solutif. 

e. Tim yang lolos dari seleksi abstrak akan berlanjut ke 

Tahap Kedua 

 

 

13 
 



 

 
2. Tahap Kedua 

a. Peserta yang dinyatakan lolos seleksi abstrak 

mengumpulkan tautan Repositori GitHub resmi karya. 

b. Panitia akan mengecek keterjalanan dan kerapihan 

kode via System Automated (Ci/CD GitHub Actions 

Build Check, Linter ESLint, dan Plagiarism Detector 

JSCPD). 

c. Tim dengan skor screeening otomatis tertinggi akan 

lanjut ke Tahap Ketigga (Final). 

 

3. Tahap Ketiga 

a. Finalis mengikuti sesi Wawancara / Presentasi karya di 

hadapan Dewan Juri. 

b. Dewan Juri melakukan pemeriksaan kebersihan & 

arsitektur kode secara langsung (Juri Cek Code) serta 

sesi tanya jawab teknis. 

c. Tim dengan total nilai tertinggi di masing-masing 

kategori (Pelajar SMA/SMK Sederajat dan Mahasiswa) 

dinyatakan sebagai pemenang.
